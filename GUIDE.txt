MODEL ARCHITECTURE
═══════════════════════════════════════════════════════════════════

Input: 256×256×3 (RGB Image)
  │
  ├─ ENCODER (Contraction Path)
  │  ├─ Level 1: Conv(64,3,3) → Conv(64,3,3) → Pool(2,2) → 128×128
  │  ├─ Level 2: Conv(128,3,3) → Conv(128,3,3) → Pool(2,2) → 64×64
  │  ├─ Level 3: Conv(256,3,3) → Conv(256,3,3) → Pool(2,2) → 32×32
  │  └─ Level 4: Conv(512,3,3) → Conv(512,3,3) → Pool(2,2) → 16×16
  │
  ├─ BOTTLENECK
  │  └─ Conv(1024,3,3) → Conv(1024,3,3)  [16×16]
  │
  ├─ DECODER (Expansion Path - with Skip Connections)
  │  ├─ UpSample → Concat(c4) → Conv(512,3,3) → Conv(512,3,3)
  │  ├─ UpSample → Concat(c3) → Conv(256,3,3) → Conv(256,3,3)
  │  ├─ UpSample → Concat(c2) → Conv(128,3,3) → Conv(128,3,3)
  │  └─ UpSample → Concat(c1) → Conv(64,3,3) → Conv(64,3,3)
  │
  └─ Output: Conv(2,1,1) + Softmax → 256×256×2 (Binary Segmentation)

Total Parameters: ~31 Million

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Issue: "Module not found"
Solution: pip install -r requirements.txt

Issue: Out of memory
Solution: Reduce batch_size, num_samples, or image_size

Issue: Poor segmentation
Solution: Increase epochs, generate more data, adjust threshold

Issue: Slow training
Solution: Use GPU, increase batch size (needs more memory)

Issue: Model not saving
Solution: Check permissions, disk space, file path
